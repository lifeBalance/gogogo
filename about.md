# Go sample course

The same three exercises as the Python course, in Go. Useful for seeing how a course written in another language fits the same shape.

Each exercise is its own Go module, with the test file next to the code the way Go expects it. Write the function, press Run to try it against the example, press Test to run `go test`.

## What you need

Nothing. The course runs on the `golang:1.25` image in an isolated virtual machine, and that image already ships the test runner, so there is no setup step.

## Sections

- **Warm-up**: Two Sum, Contains Duplicate. Maps and sets.
- **Prefix sums**: Running Sum of 1d Array. The idea behind every range-sum problem.
