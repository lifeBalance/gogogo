# Two Sum

Given a list of integers `nums` and an integer `target`, return the indices of the two numbers that add up to `target`.

Each input has exactly one solution, and you may not use the same element twice. Return the indices in any order.

## Examples

```text
nums = [2, 7, 11, 15], target = 9   ->  [0, 1]
nums = [3, 2, 4],       target = 6   ->  [1, 2]
nums = [3, 3],          target = 6   ->  [0, 1]
```

## Constraints

- `2 <= len(nums) <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- Exactly one valid answer exists.
