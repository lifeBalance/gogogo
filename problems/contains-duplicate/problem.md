# Contains Duplicate

Given a list of integers `nums`, return `True` if any value appears at least twice, and `false` if every element is distinct.

## Examples

```text
nums = [1, 2, 3, 1]              ->  true
nums = [1, 2, 3, 4]              ->  false
nums = [1, 1, 1, 3, 3, 4, 3, 2]  ->  true
```

## Constraints

- `1 <= len(nums) <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
